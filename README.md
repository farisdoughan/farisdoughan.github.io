# Minimal academic website

This is a plain static website designed for GitHub Pages.

## Files
- `index.html` - main page
- `styles.css` - styling
- `script.js` - mobile navigation
- `assets/profile-placeholder.svg` - replace with your photo later
- `assets/cv-placeholder.pdf` - replace with your real CV PDF later

## How to publish on GitHub Pages
1. Upload all files to the root of `farisdoughan.github.io`
2. In GitHub, go to Settings -> Pages
3. Set Source to deploy from the `main` branch and `/ (root)`
4. Wait for the site to deploy

## How to update the CV
Replace `assets/cv-placeholder.pdf` with your own PDF and keep the same name.
